# 📦 Inventory & Accounting Automation System

An Excel-based inventory and accounting solution that streamlines inventory management, sales tracking, and financial reporting for small businesses.

---

## 📖 About the Project

Working in accounting exposed me to the challenges many small businesses face with manual inventory records, sales reconciliation, and financial reporting. This project is my attempt to simplify those processes using a familiar tool—Microsoft Excel.

---

## 🔄 How It Works

The system follows the typical workflow of a small business.

Supplier → Purchases → Product Master → Sales → Sales Reconciliation → Profit & Loss → Dashboard

Each module updates the next, reducing manual calculations while keeping inventory and financial records synchronized.

---

## ✨ Features

### Inventory

- Product master
- Purchase recording

### Sales

- Sales recording
- Daily sales reconciliation

### Accounting

- Expense tracking
- Profit & Loss reporting

### Reporting

- Interactive dashboard
- Low-stock alerts
- Business performance insights
